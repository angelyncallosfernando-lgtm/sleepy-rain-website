Privacy Policy

Effective date: November 24, 2026

1. Introduction

Sleepy Rain Sanctuary is an independent digital content project that creates and manages relaxing ambient videos.

This policy explains how our private automation application accesses, uses, stores and protects Google user data and YouTube API data.

2. Google Account Authorization

Our application uses Google OAuth 2.0 to obtain authorized access to the channel owner's YouTube account.

The application requests the following OAuth permission:

https://www.googleapis.com/auth/youtube.upload

This permission is used to upload videos and associated content to the authorized YouTube channel.

3. Information Accessed

Our automation may process the following:

  • Google OAuth access and refresh tokens.
  • YouTube video identifiers.
  • Video titles and descriptions.
  • Video tags and category information.
  • Video visibility settings.
  • Video files and thumbnail images.
  • Upload status and API responses.

Our application does not request access to Gmail messages, Google Contacts, Google Drive files or unrelated personal data.

4. How Information Is Used

Information is used solely to operate and maintain the authorized YouTube content production workflow, including:

  • Authenticating with the YouTube Data API.
  • Uploading generated videos.
  • Setting video metadata and thumbnails.
  • Maintaining private upload visibility.
  • Recording upload results.
  • Diagnosing technical errors.

Google user data is not used for advertising, profiling, sale, unrelated analytics or training generalized artificial intelligence models.

5. Data Storage and Security

OAuth client credentials and refresh tokens are stored using GitHub Actions repository secrets in a private repository.

Temporary access tokens are obtained during authorized workflow execution. Credentials are not intentionally published in website files or workflow logs.

Reasonable security measures are used to restrict access to the automation environment. No electronic storage or transmission method can be guaranteed to be completely secure.

6. Third-Party Services

The application uses Google and GitHub services to perform authorized operations.

  • Google OAuth 2.0
  • YouTube Data API v3
  • GitHub Actions
  • GitHub Pages

Data is processed by these providers as necessary to operate the application. We do not sell Google user data or disclose it for unrelated commercial purposes.

Please review the Google Privacy Policy and GitHub Privacy Statement .

7. Data Retention and Deletion

OAuth credentials are retained only while needed to maintain authorized access.

Workflow artifacts are retained according to the configured GitHub Actions retention settings. Review artifacts are currently configured for one day and upload metadata artifacts for seven days.

Workflow logs and other platform records may be retained separately according to applicable platform settings and policies.

The channel owner can request deletion of stored application data and remove OAuth credentials from the private repository. Data will be deleted when no longer required, subject to applicable legal and platform retention requirements.

8. Revoking Google Access

Google account authorization may be revoked at any time through:

Google Account Third-Party Connections

Revoking authorization prevents the application from continuing to use the revoked Google access credentials. Previously uploaded YouTube videos are not automatically deleted.

9. Google API Compliance

Sleepy Rain Sanctuary's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google API Services User Data Policy

YouTube API Services Terms of Service

10. Website Visitors

This website does not contain account registration forms, advertising trackers or custom analytics scripts.

GitHub Pages may process technical information necessary to deliver and secure the website.

11. Changes to This Policy

This policy may be updated when our application, data practices or applicable requirements change.
